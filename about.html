ПРОЕКТ / КОМПАСВЭД

Правовой навигатор
для внешней торговли.

КомпасВЭД — концепция цифровой платформы для российских участников внешнеэкономической деятельности. Её цель — объединить проверку контрагентов и отслеживание правовых рисков в одном интерфейсе.

ЗАДАЧА

Проверка сделки не должна начинаться с десятков открытых вкладок.

Сведения об ограничениях распределены между официальными перечнями, нормативными документами и правоприменительной практикой. Специалисту нужно не только найти информацию, но и понять, относится ли она к конкретному бизнесу.

Проект ориентирован на экспортёров, импортёров, руководителей отделов ВЭД, юридические и комплаенс-подразделения.

АРХИТЕКТУРА ИДЕИ

Возможности, над которыми работает команда

Мониторинг источников

Сбор сведений из официальных санкционных списков и правовых публикаций.

Анализ контрагентов

Проверка организаций и связанных с ними лиц, включая структуру владения.

Обработка документов

Применение NLP для выделения существенных изменений в правовых текстах.

Персональные уведомления

Сообщения об изменениях, которые могут затронуть конкретные сделки.

Рекомендации и отчёты

Структурированное представление рисков и возможных дальнейших действий.

Интеграции

ТЕХНОЛОГИИ

Технологическая основа

В материалах проекта предусмотрены Python для серверной части, графовая база Neo4j для анализа связей и языковые модели для обработки правовых текстов. Это планируемая архитектура: в данном учебном сайте эти технологии не подключены.
